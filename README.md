# ADASmini

A miniature ADAS (Advanced Driver Assistance System) model built on an STM32 microcontroller. It measures the distance to obstacles ahead with an ultrasonic sensor, warns the driver with LEDs and an OLED display, and controls the motors to stop or back off when an obstacle is too close.

All drivers (GPIO, timer, I2C, OLED) are written at the **register level**, without using HAL.

## Features

- Forward distance measurement with an HC-SR04 ultrasonic sensor
- Three alert levels shown on a 128x64 SSD1306 OLED:

| Distance | State | OLED | LED | Motors |
|---|---|---|---|---|
| < 50 cm | DANGER | `DANGER` | PA4 LED on | Stop for 100 ms, then run in the alternate (back-off) mode |
| 50 - 100 cm | WARNING | `WARNING` | PA5 LED on | Run normally |
| > 100 cm | SAFE | `SAFE` | Off | Run normally |

## Hardware

- MCU: STM32F401RE
- HC-SR04 ultrasonic sensor
- SSD1306 128x64 OLED over I2C (address 0x78 in 8-bit form, i.e. 0x3C in 7-bit form)
- Motor driver: L298N
- 2 indicator LEDs
- Power: 5 V supply

## Pinout

| Function | Pin |
|---|---|
| HC-SR04 TRIG | PB8 |
| HC-SR04 ECHO | PB9 |
| Left motor | PC0 |
| Right motor | PC1 |
| OLED SCL (I2C1) | PB6 |
| OLED SDA (I2C1) | PB7 |
| DANGER LED | PA4 |
| WARNING LED | PA5 |

Note: the HC-SR04 ECHO pin outputs 5 V. PB9 is marked 5 V tolerant (FT) in the STM32F401RE datasheet, so it can be connected directly. If you move ECHO to another pin, check that it is FT first or use a voltage divider. The MCU, sensor, L298N and OLED must share a common GND.

## How it works

1. Send a 10 us pulse on the TRIG pin.
2. Measure the pulse width on the ECHO pin using TIM2 (counting at 1 MHz, i.e. 1 us per tick).
3. Distance (cm) = time (us) / 58.
4. Compare against the 50 cm and 100 cm thresholds to pick the state, then update the OLED, LEDs and motors.
5. Repeat roughly every 100 ms.

## Build and flash

1. Install [STM32CubeIDE](https://www.st.com/en/development-tools/stm32cubeide.html).
2. Clone the repository:
   ```bash
   git clone https://github.com/trantoan1103/ADASmini.git
   ```
3. In STM32CubeIDE: **File -> Import -> Existing Projects into Workspace**, then select the cloned folder.
4. Build (**Project -> Build Project**) and flash the board with ST-LINK.
